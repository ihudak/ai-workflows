# Gates — the ID-grammar gate

Loaded with `.claude/rules/gates.md`, whose `paths:` it shares and whose opening rule binds every gate. Split out of `.claude/rules/gates.md` to keep that file under 20,000 characters; repo-wide rules are in `CLAUDE.md`; evidence is in `docs/maintainers/rationale.md`.

## ID-grammar gate (`scripts/check-id-grammar.sh`)

It runs on every push via `.github/workflows/validate-catalog.yml` — preceded there by `--selftest`, which asserts, per fixture, the exit code **and every ID form the gate must have named** — one grep per alternation of `PATTERN`. `TH`, a threat's ID in an ARD's threat model (`[TH#n]`), joined the bracketed and bare prefix alternations of `PATTERN` when nothing in the tree wrote its dash form, measured at 0 on 2026-11-14 over every file the gate scans; `scripts/fixtures/prd-bad.md` names a bracketed and a bare dash form of it, so dropping `TH` from either alternation fails the selftest. `DT`, an entry's ID in a design's threat review (`[DT#n]`), joined those two alternations the same way, measured at 0 on 2026-11-14, with a bracketed and a bare dash form in the same fixture. **The open-bracket alternations** take a dash-form id after a `[` that no `]` closes — a form that passed both the bracketed alternation, which needs the `]`, and the bare one, which refuses a `[` before the id — with what follows the id held, as on the bare one, to neither `]`, a letter, a digit nor `_`. They joined with every prefix and `SM-C` when nothing the gate scans wrote such a form, measured at 0 on 2026-11-26 over every file the gate scans; `scripts/fixtures/prd-bad-open-bracket.md` names one per prefix and `SM-C`, and a line ending on each alternation's form, so dropping a prefix, either alternation or either one's end-of-line case fails the selftest. The exit code alone is not enough: each negative fixture carries several violating lines, so any surviving alternation holds the exit at 1. `scripts/validate-catalog.py`'s own `--selftest` does the same, ahead of its run. ([why](../../docs/maintainers/rationale.md#id-grammar))

Of the `id-grammar-ok` markers, one accepts the legacy form as a tolerant reader — `workflows-core:ard-resolution`; the others are the reviewers that check identifier integrity and must quote the form they reject. Re-derive the census with `grep -rn 'id-grammar-ok' plugins/ --include=*.md | grep -v CHANGELOG` — scoped to `plugins/`, not to one plugin, since the split put `workflows-core:ard-resolution`'s marker outside `dev-workflows` rather than adjusting it. The spec/design numbered-ID namespace is deliberately outside this grammar and unchanged; `scripts/spec-id-baseline.txt` is its census tripwire, and `./scripts/check-id-grammar.sh --baseline` trips it: it runs the file's Verify recipe, fails on any difference, and runs on every push right after `--root .`, its cases in the same `--selftest`. A count that moved is traced to its files before the file is regenerated, with a dated header paragraph naming each delta's source; it went unrun until batch B29, and its header records drifts found weeks late.
