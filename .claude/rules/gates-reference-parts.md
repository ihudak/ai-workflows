# Gates — the reference-parts gate

Loaded with `.claude/rules/gates.md`, whose `paths:` it shares and whose opening rule binds every gate. Split out of `.claude/rules/gates.md` to keep that file under 20,000 characters; repo-wide rules are in `CLAUDE.md`; evidence is in `docs/maintainers/rationale.md`.

## Reference-parts gate (`scripts/reference-parts.py`)

A split shared reference stays one source file under `plugins/workflows-core/references/`: a `<!-- reference-parts` declaration directly after its H1 line names its parts, and `<!-- part: <name> -->` … `<!-- /part -->` regions say which part owns each line. `generate` assembles each requestable part — with the always part, the parts it needs and the reference's rule index — into a committed file under `plugins/workflows-core/reference-parts/<name>/`, and deletes every file there that no declaration produces. **A generated file is never edited by hand**: edit the source and run `generate`. The marker syntax, the index's name matching and the generated layout are written in the script's own docstring and nowhere else. It is a script of its own, never a check in `scripts/check-docs.sh`, whose body the internal editions share byte for byte. ([why](../../docs/maintainers/rationale.md#reference-parts))

**`check-parts`** fails on a malformed declaration or marker, a non-blank line outside every region, a nested region or one closed inside a fenced block, anything but exactly one `always` part, a need that names no part, one rule name in two parts, a relative link in a split source, and a generated file that is stale, missing or produced by no declaration — it regenerates in memory and compares byte for byte. A positional pointer inside a part (*above*, *below*, *the next section*) prints as a `FLAG` line and does not fail.

**`check-citations`** fails when the loader skill's split list is not the declared set; when a file in a dependent plugin's `commands/`, `agents/` or `references/` cites a split reference without the load-by-part preamble as a paragraph of its own; on a part request naming no requestable part; on an explicit part request whose own sentence names a rule that its load — the part, with its needs, and no other call's — does not hold: a call converted to the wrong part; on a sentence that cites a reference no other way, in a paragraph making explicit loads of it, naming a rule that the loads made at or before that sentence do not hold together — never a later load, since a run applies a rule as it reads it; and on a citation, explicit or bare, naming a rule held in a private part, whose text no part load brings. A sentence carrying its own citation of the reference is judged as that citation. A bare citation is placed on the part of each rule its sentence names, on every one where it names rules of several, since the preamble has the run load each before applying its rule; one naming no rule the index holds is placed on the whole reference, which is what the preamble then loads, so it passes too. Both count in the `placed N, whole M` census printed per reference, and `--verbose` lists each whole one. **Both subcommands fail closed**: either fails when no reference carries a declaration, and `check-citations` also fails on a declared reference no dependent plugin cites.

`.github/workflows/validate-catalog.yml` runs its `--selftest` — one fixture tree per case under `scripts/fixtures/reference-parts/`, each case asserting the exit code, what it must print and, for a red case, its number of problems — and its `run:` steps say which subcommands run on every push. No case count is written here: `--selftest` prints one `ok` line per case.

**What it cannot see:** whether a run loads a part when it reaches the citation — the preamble tells it to, and the rule-by-rule reading and the live runs check that it does. It reads a rule's name only as an italic, bold, backticked or quoted span or a `§` reference in the citation's own sentence — and, where a paragraph makes explicit loads, in each of its sentences that cites the reference no other way — so a citation naming its rule another way ("rule 6", "the overflow rule") counts whole, and the census is how such citations are found; and whether a flagged pointer crosses a part boundary is the reading's call, not the gate's.
