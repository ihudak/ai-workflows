Measured 2026-11-05 on every ref of every specs repository on this machine: one such record, `PRD-BOOK-2-01`'s `reconciliation-20261012.md` on the e2e copies, and no `code-defect-log.md` anywhere, so no flag is lost. Parts 2 and 3 shipped in product-workflows 3.77.0: a slice's flag readers take every record, not only the newest, of every slice under its parent and of every slice its `depends-on:` names.
- **MIDRUN-2S — two sessions on one checkout are not protected from each other's switches (the STAY-2 and MIDRUN-B4 design, `docs/superpowers/specs/2026-11-10-stay2-midrun-design.md` §3.3; its plan's P18).** A run typed mid-run is told apart by reading this session's own state records (`specs-repo-git` §3.5 and §7), so a command run in a second Claude Code session on the same specs checkout still switches the branch away under the first session's open run, and its flush or its end can commit that run's in-progress session files with its own. Reading every session's records would hold every week-old abandoned run of every session open, since a record reads as open for seven days. `specs-repo-git` §3.5 states it (*Not covered: two sessions on one checkout*), and `docs/maintainers/rationale.md`'s `stay-landing` section says why.
