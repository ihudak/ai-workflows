# LADDER-ORDER batch 4 — `/create-ard` and `/specify` stop on a slice whose ledger fails — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** On a BRD-route slice, `/product-workflows:create-ard` and `/product-workflows:specify` stop unless the slice's `coverage-ledger.md` is readable, no row its `brd-link.md` claims is `unallocated`, and at least one is `covered-here`; no stop or offer in the family names either run for a slice on which it would stop; and the BRD route's not-handed-off stops gain the committed form.

**Architecture:** Everything is prose in command, reference and page files, executed literally by agents. The test is `product-workflows:coverage-ledger-format` §5's, made whole there (Task 1) and applied by the two commands in a Phase 0 step of their own (Tasks 2, 3). `workflows-core:phase-handoff` §4.4's `prd.md` rung restates it once for the plugins that cannot load that reference (Task 4), and every reader outside `product-workflows` takes it by citation (Task 5). The route's own offers become conditional (Task 6); the not-handed-off stops follow §4.4 row F (Tasks 7, 8). No script changes.

**Tech Stack:** Markdown command, reference and page files; the repository's gates, run as the `run:` steps of `.github/workflows/validate-catalog.yml`.

**Spec:** `docs/superpowers/specs/2026-11-14-ladder-order-design.md` — §5.4 (its table and nine bullets) and §5.5's **Batch 4** list (twelve bullets, as binding as §5.4); §4 (the rule, the stop contract); §2 (M1, M2, M4, L5, L8, L10, L12); §7, §10, §11, §12. Measured on this tree (`main` at `67b4c740`): `docs/superpowers/plans/2026-11-17-ladder-order-b4-measurements.md`, cited as *M §n*. The sweep population, rows `S-1` to `S-117` and `N-1` to `N-8`, each with the task that takes it: `docs/superpowers/plans/2026-11-17-ladder-order-b4-sweep-population.md` (*the population file*). Where this plan and the design disagree, the design wins and the disagreement is reported.

Abbreviations: CPRD, ARD, SPEC, INT, REC = `plugins/product-workflows/commands/` `create-prd.md`, `create-ard.md`, `specify.md`, `brd-interview.md`, `brd-reconcile.md`; CLF = `plugins/product-workflows/references/coverage-ledger-format.md`; PH, NPO = `plugins/workflows-core/references/` `phase-handoff.md`, `next-phase-offer.md`; IMPL, DES, CONF, RDY = `plugins/dev-workflows/commands/` `implement.md`, `design.md`, `conformance.md`, `ready.md`; DOC, RN = `plugins/docs-workflows/commands/` `document.md`, `release-notes.md`; SCAN = `plugins/security-workflows/commands/scan.md`; "page X" = `plugins/<plugin>/docs/commands/X.md`.
