# Run Flags Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `--skip-costs`, `--skip-feedback` and `--enforce-model=<m>` (with `WORKFLOWS_*` env defaults) to every applicable command of the four family plugins.

**Architecture:** One new shared authority, `workflows-core:run-flags`, owns the flag grammar, env resolution, model aliases, the `run_flags` record and two entry points (`strip-run-flags`, `skip-cost`). `classification.md` gains §2.2 (cheap chain) and §10 (enforced model); `feedback-emission.md` gains the defect predicate and `emit-bugs`; a new `defect-reporter` agent replaces `impl-maintenance` under `--skip-feedback`; `session-cost.py` gains `--advance-only`. Each command gets four standard edits (usage, Phase 0 strip, maintenance guard, cost guard) plus the pinned-dispatch rewording.

**Tech Stack:** Markdown prose executed by agents; Python 3 stdlib (`session-cost.py`); bash gate scripts.

**Spec:** `docs/superpowers/specs/2026-09-28-run-flags-design.md`

## Standard edit blocks (used verbatim by Tasks 6–9)

Each command task applies only the blocks whose flag applies to that command (see the applicable sets above).

**Block U — usage line.** Append to the command's `Usage:` line (and to the `## Synopsis` fence of its `docs/commands/<name>.md` page) the applicable subset, in this order: ` [--skip-costs] [--skip-feedback] [--enforce-model=<model>]`.

**Block P — Phase 0 strip.** Insert as the first sub-step of the command's first argument-parsing step (where it already strips `--no-docs` etc., put this sentence *before* that one):

> **Strip the run flags first.** Execute `strip-run-flags` (`Skill(skill: "workflows-core:reference", args: "run-flags strip-run-flags")`) on `$ARGUMENTS` before anything else reads a token: it removes `--skip-costs`, `--skip-feedback` and `--enforce-model` (with any `=value`), resolves each against its environment default, and returns the `run_flags` record this run carries to its maintenance, cost and routing steps — or stops with `RUN_FLAGS_BAD_MODEL` / `RUN_FLAGS_MODEL_UNAVAILABLE` before any write. Every later step parses only what it leaves.

**Block M — maintenance guard.** Insert at the top of the numbered steps of the command's maintenance/feedback phase (the phase that dispatches `impl-maintenance`):

> **Under `run_flags.skip_feedback`** (`workflows-core:run-flags` §4), dispatch `workflows-core:defect-reporter` instead of `impl-maintenance` in step 1, with the same handoff and `model: <§2.2 cheap chain, or run_flags.enforced_model>`; if it returns at least one defect, persist them with `emit-bugs` (`Skill(skill: "workflows-core:reference", args: "feedback-emission emit-bugs")`) in place of `emit-auto`, otherwise load nothing. Surface `Session feedback: bugs-only (--skip-feedback) — N defect(s) persisted` or `— no defects` as this phase's only output. Capture-at-block (`emit-block`) is unaffected by the flag.

**Block C — cost guard.** Insert as the first paragraph of the command's cost phase (the phase that calls `emit-cost`), before the `emit-cost` sentence:

> **Under `run_flags.skip_costs`**, do not call `emit-cost` and do not load `cost-emission`: execute `skip-cost` (`Skill(skill: "workflows-core:reference", args: "run-flags skip-cost")`) instead, which advances the checkpoint and drops any deferred record, and surface `Session cost: skipped (--skip-costs)` (or `(WORKFLOWS_SKIP_COSTS)`). The resume-pointer write and the terminal `commit-artifacts` step below run unchanged either way.

**Block R — pinned-dispatch rewording.** In every line matched by `grep -n "frontmatter-pinned" <file>`, replace the phrase `no override` with `no override unless §10 enforces a model` (and `no \`model:\` override needed` with `no \`model:\` override needed unless §10 enforces a model`). Where the dispatch's own `→ Agent (…, model: …)` line names a model, append `; under §10, run_flags.enforced_model` inside that `model:` placeholder.

**Block G — enforcement record.** In the command's `model_routing` YAML example (Phase 1.5 / Classify step), add after `current_model:`:
```yaml
  enforced_model: <run_flags.enforced_model, or omit>   # §10: when set, every *_model below equals it and routing: bypassed
```
