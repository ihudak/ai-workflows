- `declined`: *Not this time*.
- `added`: a new model was drafted.
- `refined`: *Refine the threat model*.
- `redisposed`: *Re-dispose only the stale threats*.

### The decision-pair and cross-folder forms (R1)

- **A decision pair** names one decision by the ARD file that holds it, because each ARD file numbers its own series.
  - Its form is `<ARD file> [AD#N]`, where `<ARD file>` is the basename of an ARD file in the model's own folder: `ard.md [AD#3]` or `ard-payments.md [AD#2]`.
  - For the PRD-level ARD an Epic inherits, the form is `[[<PRD-KEY>]] ard.md [AD#4]`, with the PRD folder's key in the wikilink form, which pre-lint's auto-link check discards (its *Discard a hit ONLY when …* rule).
  - Several pairs are joined by `, `.
- **A threat in another folder** is `[[<KEY>]] [TH#N]`. Every model numbers from `[TH#1]`.

### `threat-model.md` — the shape (Task 2 writes it into the format; every later task consumes it)

````markdown
---
kind: threat-model
key: <KEY>                    # this folder's key — must match the folder name
status: draft | reviewed      # the value the run writes in the ARD's own status:
upstreams: …                  # written only by lineage.py
accepted: …                   # written only by lineage.py
---

# <PRD or Epic title> — threat model

## Scope

- **Components:** <id>, <id>, …
- **Contract rows:** <pair>, <pair>, … | none

## Not considered

- <component id | contract pair> — <why it was left out>

## Threats

### [TH#1]: <title>

- **Category:** S | T | R | I | D | E | —
- **Where:** <component id>[, <component id>…][; contract <pair>]
- **Threat:** attacker: <who>; action: <what they do>; asset: <what is at stake>
- **CWE:** [CWE-<n>](https://cwe.mitre.org/data/definitions/<n>.html) | —
- **Disposition:** Mitigated by <pair>[, <pair>…][; the rest deferred to design: <what>] | Deferred to design: <what the design must answer> | Accepted — <owner>; <reason>; review by <YYYY-MM-DD>
- **Superseded by:** [TH#M] — <why>        (a superseded threat only)
- **Withdrawn:** <why>                     (a withdrawn threat only)

## Inherited threats                       (an Epic-level model only)

- [[<PRD-KEY>]] [TH#2] <title> — <its Disposition, as the PRD-level model states it>
````

- `## Not considered` reads `_None._` where nothing was left out.
- Every one of the five fields is present on every threat.
- `—` marks an empty Category or CWE.
- **A live threat** is one with neither `**Superseded by:**` nor `**Withdrawn:**`.
- **The Disposition holds exactly one of the three forms.** `Mitigated by …; the rest deferred to design: …` is one form.
- `<n>` in a CWE link has no leading zeros, as `ard-format`'s *A CWE in Prevents* has it.
- **An Epic-level threat's Where** holds the Epic's `target:` id. Where it crosses a boundary, it adds `; contract [[<PRD-KEY>]] ard.md [AD#N]`.
- **A BRD-route slice's model** has no `## Inherited threats` (design T4).

### The check (format §6; Phase 4.3 steps 3 and 8, and Phase 6)

The check is mechanical and asks nothing. It reads the model as the run holds it and the ARD files as the run holds them at that point. At Phase 4.3 those are this run's drafts. At Phase 6 they are the files as just written. For `[[<PRD-KEY>]] ard.md`, it reads the inherited ARD Phase 2 resolved.

A live threat is **stale** where any of these holds:
1. A component id in its **Where** is not in `threat_model.set`.
2. Its `contract <pair>` names no interface-table row of that ARD file whose `AD` is that id, or that decision is not live.
3. A pair in its `Mitigated by` names no `### [AD#N]` in that ARD file, or names one carrying `**Superseded by:**` or `**Withdrawn:**`.

Nothing else is checked. An acceptance past its review date is not stale: a refine lists it (Task 6 step 7).
