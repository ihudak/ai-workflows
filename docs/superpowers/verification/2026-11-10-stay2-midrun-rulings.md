# Rulings — STAY-2 and MIDRUN-B4 (a stayed run's session files land on the default branch; a run typed mid-run switches nothing)

The branch `fix/stay2-midrun` makes a run whose specs-repository preflight had to stay on a plugin branch it would have left commit its own session-file change on `<default>` without moving the checkout (STAY-2), and makes a command typed while another run of the same session is open switch nothing and commit only its own change (MIDRUN-B4). The same mechanism fixes the record collision of one command typed twice and replaces D5's merged-branch hold, which git 2.43 refuses to carry. Task 9b, added by the user, takes git's `--guess` and implicit tracking out of every branch creation and switch in the family, so none half-moves a checkout where `.git/config` is read-only. Its plan is `docs/superpowers/plans/2026-11-10-stay2-midrun.md`, and its design `docs/superpowers/specs/2026-11-10-stay2-midrun-design.md`. Below, SRG means `workflows-core:specs-repo-git`.
