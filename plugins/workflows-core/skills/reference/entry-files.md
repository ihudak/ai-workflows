# Reference loader — entry-point rules

Read on a request on a reference that the `reference` loader skill's list of the entry points that read their own file names, as that skill says.

An entry point's own file holds the entry point and the sections it needs, and names them in the line under its title, which ends with the file's own line count: a run that reads the file in more than one range takes its length from its first range, with no `wc -l`. The file for `phase-handoff branch-check` holds §1, §2.2 and §6, and in part §3.3 ("Row B′'s remedy"). The file for `phase-handoff require-on-main` holds the text before §1, §1, §2.2, §2.6.1, §3 and §4.4, and in part §4.0 ("never infer") and §5 ("rule 2" and "rule 3"). A request whose second argument names one of these entry points reads its file and executes the entry point from it. A request with no second argument, made for a citation of a section an entry point's file holds — of one it holds in part, only for the text its quoted phrase names — executes nothing and needs only that section's text, so it is a lookup: wherever that text is in this conversation word for word, from a read of either file or of the whole reference made in this run, in whatever phase, it works from that text and reads nothing. Only where that text is not in front of you does it read: the file, inside a `##` section whose text also requests that file's entry point, before the citation or after it; the whole reference, anywhere else. So a `##` section requesting an entry point reads its file at most once, wherever the citation stands: where the citation comes first and reads the file, the request executes the entry point from that read, made in the current phase; where the request reads it first, the citation is a lookup. Every other request on that reference reads the whole reference, as the loader's paragraph opening "To read the whole reference" says: a second argument naming an entry point with no file of its own, and a request with no second argument made for a citation of a section neither file in front of you holds, of a section held in part for text its quoted phrase does not name — in `require-on-main`'s file §4.0 for anything but its *Never infer* rule and §5 for any rule but rules 2 and 3, in `branch-check`'s §3.3 for anything but *Row B′'s remedy* — or of no section. A read of the whole reference covers both files, within the loader's bound on reuse, as any read does.
